# Changelog

Add this at the top of your changelog:

### TL;DR

- Built a full end-to-end compiler pipeline for `.loi` files
- Source code now flows through:
  `Lexer → Parser → AST → Semantic IR → LLVM IR → Bitcode → Native executable`
- Replaced string-based “fake backend” with real LLVM code generation (Inkwell)
- Added watch mode for automatic rebuilds on file changes
- Introduced typed IR as the core intermediate representation
- Outputs now produce real executables via `clang` linking
- Basic test suite added for lexer, parser, IR, and full pipeline
- Compiler is currently functional but LLVM lowering is still mostly stubbed (prints instead of real instructions)

## 2026-06-05 — Compiler Pipeline Migrated to LLVM

### Added

#### Core Compiler Pipeline

Implemented a complete compilation pipeline:

```text
.loi
 ↓
Lexer
 ↓
Parser
 ↓
AST
 ↓
Semantic Analysis
 ↓
IR
 ↓
LLVM Lowering
 ↓
LLVM Bitcode (.bc)
 ↓
Native Executable
```

---

#### Project Module Structure

Organized compiler into major phases:

```text
src/
├── frontend/
│   ├── lexer.rs
│   ├── parser.rs
│   └── ast.rs
│
├── middle/
│   ├── semantic.rs
│   ├── ir.rs
│   └── optimize.rs
│
├── backend/

│   ├── llvm.rs
```

---

#### LLVM Backend

Added LLVM code generation infrastructure using Inkwell.

Current backend:

```text
IR
 ↓
LLVM Module
 ↓
Bitcode (.bc)
```

Generated LLVM modules now contain:

```llvm
define i32 @main() {
entry:
  ret i32 0
}
```

which successfully links into native executables.

---

#### Native Executable Generation

Added compilation flow:

```text
IR
 ↓
LLVM Bitcode (.bc)
 ↓
clang
 ↓
Native Executable
```

Generated outputs:

```text
tmp/output/
├── example.bc
├── example
```

---

#### Recursive IR Traversal

Implemented recursive LLVM lowering skeleton supporting:

```rust
IROp::Module
IROp::Assign
IROp::Load
IROp::ExprStmt
IROp::Print
IROp::If
IROp::While
IROp::Block
IROp::Function
IROp::Call
IROp::Return
IROp::Branch
IROp::Nop
```

Current implementation is stubbed and ready for incremental lowering.

---

#### Watch Mode

Added filesystem watch mode.

Compiler can now automatically rebuild when `.loi` files change.

Example:

```bash
cargo run -- --watch targets/examples
```

---

#### Config-Based Compilation

Introduced compiler configuration abstraction.

```rust
Config {
    input,
    output,
    watch,
}
```

Pipeline no longer depends on hardcoded paths.

---

#### Typed IR

Introduced type-aware IR expressions.

```rust
pub struct TypedExpr {
    pub expr: Expr,
    pub ty: Type,
}
```

Supported types:

```rust
Type::I32
Type::i64
Type::Bool
Type::Str
Type::Void
Type::Ptr(...)
```

### Known Limitations

LLVM lowering is currently stubbed.

The compiler generates:

```llvm
define i32 @main() {
entry:
  ret i32 0
}
```

for all input programs.

The following IR nodes do not yet emit real LLVM instructions:

```rust
Assign
Load
Print
Binary
Unary
Call
If
While
Return
```
